## Color
### Text Color
1.
    | Color | Code | Rendering |
    | :--- | :--- | :--- |
    | Red | `$${\color{red}\text{Red}}$$` | $${\color{red}\text{Red}}$$ |
    | Green | `$${\color{green}\text{Green}}$$` | $${\color{green}\text{Green}}$$ |
    | Light Green | `$${\color{lightgreen}\text{Light Green}}$$` | $${\color{lightgreen}\text{Light Green}}$$ |
    | Blue | `$${\color{blue}\text{Blue}}$$` | $${\color{blue}\text{Blue}}$$ |
    | Light Blue | `$${\color{lightblue}\text{Light Blue}}$$` | $${\color{lightblue}\text{Light Blue}}$$ |
    | Black | `$${\color{black}\text{Black}}$$` | $${\color{black}\text{Black}}$$ |
    | White | `$${\color{white}\text{White}}$$` | $${\color{white}\text{White}}$$ |
    | Yellow | `$${\color{yellow}\text{Yellow}}$$` | $${\color{yellow}\text{Yellow}}$$ |
    | Orange | `$${\color{orange}\text{Orange}}$$` | $${\color{orange}\text{Orange}}$$ |
2.
    | Code | Output |
    | :--- | :--- |
    | `$\color{Green}{\textsf{Normal, colored text}}$` | $\color{Green}{\textsf{Normal, colored text}}$ |
    | `$\color{Blue}{\textbf{Normal, Bold and colored text}}$` | $\color{Blue}{\textbf{Normal, Bold and colored text}}$ |
    | `$\color{Purple}\large{\textsf{Large, colored text}}$` | $\color{Purple}\large{\textsf{Large, colored text}}$ |
    | `$\color{Yellow}\large{\textbf{Large, Bold and colored text}}$` | $\color{Yellow}\large{\textbf{Large, Bold and colored text}}$ |
    | `$\color{Red}\Huge{\textsf{Huge, colored text}}$` | $\color{Red}\Huge{\textsf{Huge, colored text}}$ |
    | `$\color{Orange}\Huge{\textbf{Huge, Bold and colored text}}$` | $\color{Orange}\Huge{\textbf{Huge, Bold and colored text}}$ |
